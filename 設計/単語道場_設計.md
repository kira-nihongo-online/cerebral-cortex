## 保存場所

GitHub / projects / tango-dojo

## 内容

【全体構成】
GitHub Pages上で動作する単語学習用Webアプリとして構成する。
Google Apps Scriptをデータ・画像取得用の外部APIとして利用する。

【データ取得】
URLのlessonパラメータから教材を指定する。
Google Apps Scriptから単語データを取得し、カード配列として保持する。

【カード構成】
1枚の単語カードを表面と裏面に分ける。

表面：
・意味画像
・日本語画像

裏面：
・意味画像
・タイ語
・英語
・メモ

カードをクリックすると表面と裏面を切り替え、裏面から次のカードへ進む。

【画像処理】
Google Apps Script経由で画像URLを取得する。
取得した画像URLをキャッシュし、同じ画像を再取得しない。
現在のカードだけでなく、次のカード以降の画像を先読みして表示速度を確保する。

【音声】
日本語とタイ語の音声読み上げに対応する。
音声設定がONの場合、カード表示時に表面では日本語、裏面ではタイ語を読み上げる。

【画面構成】
・ヘッダー
  ├ ロゴ
  ├ 教材タイトル
  ├ 進捗表示
  └ 設定ボタン
・中央
  └ 単語カード
・左下
  └ 音声ボタン

【設定】
設定モーダルから音声、メモなどの表示・動作設定を変更できる。

【表示制御】
初回はロゴを表示し、データ取得後に単語カードを表示する。
カードの進捗を「現在番号／総カード数」で表示する。
