## 内容

【全体構成】
GitHub Pages上で動作するWebアプリとして構成する。
HTMLを画面本体とし、panel.jsで翻訳・音声・単語サポートなどの処理を行う。

【画面構成】
・ヘッダー
  ├ ロゴ
  └ Class Weaponタイトル

・授業翻訳
  ├ 入力言語選択
  ├ 翻訳言語選択
  ├ 入力欄
  ├ 音声入力
  ├ 翻訳
  ├ クリア
  └ 音声再生

・結果エリア
  ├ 翻訳結果
  └ 単語サポート

【授業翻訳】
日本語・タイ語・英語を入力言語として選択できる。
日本語・タイ語・英語のいずれかを翻訳先として選択できる。
入力した文章を翻訳し、翻訳結果を表示する。

【単語サポート】
翻訳結果とは独立した領域として右側に表示する。
日本語モードとタイ語モードを切り替えられる。

【音声】
マイクボタンによる音声入力に対応する。
入力した文章および翻訳結果の音声再生に対応する。

【補助機能】
入力欄と翻訳結果をコピーできる。
クリアボタンで入力内容をリセットする。

【外部ライブラリ】
kuromoji.jsを読み込み、日本語の形態素解析に利用する。
panel.jsを読み込み、アプリケーションの主要処理を実装する。
