# 朗読プロンプター_設計

## プロジェクト

朗読プロンプター_2026.8.22

## 情報の種類

設計

## 検索キーワード

朗読プロンプター、reading-prompter、設計

## 保存場所

GitHub / GAS

## 内容

【全体構成】
GitHub Pages上で動作する単一ページのWebアプリとして構成する。

【画面構成】
・ヘッダー
  ├ ロゴ
  ├ アプリ名
  ├ モード切替
  └ 操作エリア
     ├ 再生
     ├ 一時停止
     ├ リセット
     ├ 音声ON/OFF
     ├ スクロール速度
     └ タイマー

・ビューア
  ├ 教材画像表示領域
  └ READ LINE

【教材データ構成】
授業モード：
mina/
 └ lessonXX/
    ├ 001.jpg
    ├ 002.jpg
    └ lessonXX.mp3

コンテストモード：
contest/
 └ contest名/
    ├ 001.jpg
    ├ 002.jpg
    └ …

【モード構成】
授業モードとコンテストモードを同一アプリ内に実装する。
モード切替時に表示画像と操作仕様を切り替える。

【音声構成】
授業モード：
教材フォルダ内のMP3を再生する。

コンテストモード：
Google Apps ScriptからTTS原稿を取得し、Web Speech APIで読み上げる。

【スクロール構成】
・画像を縦方向に連続配置する。
・手動スクロールに対応する。
・授業モードでは設定した速度で自動スクロールする。
・コンテストモードでは制限時間から自動スクロール速度を算出する。

【READ LINE】
画面上に固定表示し、マウスまたはタッチ操作で上下に移動できる。

【URLによる教材指定】
lessonパラメータで授業教材を指定する。
contestパラメータでコンテスト教材を指定する。

【外部連携】
コンテストモードのTTS原稿取得にGoogle Apps Scriptを使用する。
