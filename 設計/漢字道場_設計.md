システム構成

漢字道場は、以下の構成で動作する。

Googleスプレッドシートで漢字データを管理する。
Google Driveに保存された漢字カード画像のFile IDを管理する。
Google Apps Scriptで課ごとの漢字データを取得するAPIを提供する。
GitHub PagesのWebアプリから課番号を指定してAPIへアクセスする。
APIから取得した漢字・ひらがな・タイ語・表画像・裏画像をWebアプリで使用する。
GoogleスプレッドシートからGitHub Pagesの各課URLを発行する。
Googleスプレッドシート

確認できるシート：

漢字リスト
自動ダウンロードURL
URL発行
漢字リスト

確認できる列：

A列：課
B列：No
C列：漢字
D列：ひらがな
E列：タイ語
F列：frontFileId
G列：backFileId

「漢字リスト」には課ごとの漢字データを登録する。

F列には表画像のFile ID、G列には裏画像のFile IDを登録する。

自動ダウンロードURL

「自動ダウンロードURL」シートが存在する。

今回確認した資料では、シートの具体的な列構成・処理内容までは確認できない。

URL発行

「URL発行」シートを使用する。

確認できる列：

A列：課
B列：スタートURL

各課のGitHub Pages URLを課番号ごとに管理する。

URL形式：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=課番号

確認できる例：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=1

「各課URL発行」ボタンが配置されている。

Google Apps Script

Google Apps Scriptから「漢字リスト」シートのデータを読み込み、GitHub Pagesから利用できるJSON APIを提供する。

API

doGet(e)をWeb APIの入口として使用する。

lessonパラメータが指定されていない場合はエラーJSONを返す。

lessonが指定された場合はgetLessonData(lesson)を実行し、該当課のカードデータをJSON形式で返す。

課データ取得

getLessonData(lesson)では、以下のスプレッドシートを使用する。

スプレッドシートID：

1VZxlEtek4WJRMZVYCkuTEAI2ZfjediJxFYkVuR8S2K4

使用シート：

漢字リスト

A列の課番号を指定されたlessonと照合する。

一致した行から以下を取得する。

C列：漢字
D列：ひらがな
E列：タイ語
F列：表画像File ID
G列：裏画像File ID

APIでは以下のデータとして返す。

kanji：漢字
hiragana：ひらがな
thai：タイ語
front：表画像URL
back：裏画像URL

画像URL

File IDから画像URLを生成する。

形式：

https://lh3.googleusercontent.com/d/ + File ID

課ごとのシート生成

selectLesson()から課番号を指定してcreateLessonSheet(lesson)を実行できる。

createLessonSheet(lesson)では、「漢字リスト」から指定した課のデータを抽出する。

出力シート名：

第 + 課番号 + 課

既存のシートがある場合は内容をクリアして再生成する。

URL生成

generateLessonUrls()では、「漢字リスト」A列から課番号を取得する。

課番号を数値化し、重複を除去して昇順に並べる。

「URL発行」シートをクリアし、以下のヘッダーを設定する。

課
スタートURL

その後、各課のGitHub Pages URLを生成する。

課データ取得

WebアプリではURLのlessonパラメータを取得する。

例：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=14

このlessonをGoogle Apps Script APIへ渡して、指定課のカードデータを取得する。

カード表示

APIから取得したデータをcardsとして保持する。

各カードには、

kanji
hiragana
thai
front
back

が含まれる。

表面表示時はfront画像、裏面表示時はback画像を表示する。

カード操作

画面をクリックすると次の状態へ進む。

Enterキーでも次へ進む。

Backspaceキーでは前のカードへ戻る。

カードには表面・裏面の状態があり、表面から裏面へ切り替えた後、次のカードへ進む構成になっている。

正解数

「正解」ボタンを押すことで現在のカードを正解として記録する。

同じカードについては一度だけ正解数を加算する。

画面には、

正解：○ / ○

の形式で正解数を表示する。

進行状況

画面上に、

現在のカード番号 / 全カード数

を表示する。

答えを書く領域

WebアプリにはCanvasによる記入領域がある。

マウスおよびタッチ操作で線を描くことができる。

「クリア」ボタンでCanvasの内容を消去する。

画面表示
