目的

課ごとの漢字カードをWeb上で表示し、漢字の表面を見て答えを書いた後、画面操作で裏面を確認する。

Googleスプレッドシートで漢字データと画像File IDを管理し、Google Apps ScriptをAPIとして使用する。

Googleスプレッドシート

確認できるシート：

漢字リスト
自動ダウンロードURL
URL発行
漢字リスト

確認できる列：

A列：課
B列：No
C列：漢字
D列：ひらがな
E列：タイ語
F列：frontFileId
G列：backFileId

課ごとの漢字データを管理する。

F列には表画像のFile ID、G列には裏画像のFile IDを登録する。

URL発行

「URL発行」シートでは、課ごとのGitHub Pages URLを管理する。

列：

A列：課
B列：スタートURL

URL形式：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=課番号

例：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=14

自動ダウンロードURL

「自動ダウンロードURL」シートが存在する。

今回確認した資料からは、具体的な列構成・処理内容までは確定できない。

Google Apps Script
API

doGet(e)をAPIの入口とする。

URLにlessonが指定されていない場合はエラーをJSONで返す。

lessonが指定されている場合は、指定された課のデータを取得してJSON形式で返す。

データ取得

getLessonData(lesson)では、以下のスプレッドシートを使用する。

スプレッドシートID：

1VZxlEtek4WJRMZVYCkuTEAI2ZfjediJxFYkVuR8S2K4

使用シート：

漢字リスト

A列の課番号と指定されたlessonを照合する。

一致した行から以下を取得する。

C列：漢字
D列：ひらがな
E列：タイ語
F列：表画像File ID
G列：裏画像File ID

APIで返すデータ：

kanji
hiragana
thai
front
back

画像URL

File IDから以下の形式で画像URLを生成する。

https://lh3.googleusercontent.com/d/ + File ID

課ごとのシート生成

selectLesson()で課番号を入力すると、createLessonSheet(lesson)を実行する。

指定課のデータを「漢字リスト」から抽出し、

第○課

という名前のシートを作成する。

既存の場合は内容をクリアしてからデータを入れ直す。

URL発行

generateLessonUrls()では、「漢字リスト」A列から課番号を取得する。

課番号を数値化し、重複を除去して昇順に並べる。

「URL発行」シートをクリアし、

A列：課
B列：スタートURL

を作成する。

GitHub PagesのURLに課番号をlessonパラメータとして付けて発行する。

File ID取得

Google Driveのカード画像からFile IDを取得し、「漢字リスト」へ登録する。

使用するGoogle DriveフォルダID：

画像ファイル名：

漢字_front.png
漢字_back.png

取得した表画像File IDをF列、裏画像File IDをG列へ登録する。

処理範囲：

課指定

URLのlessonパラメータから課番号を取得する。

例：

https://kira-nihongo-online.github.io/kanji-dojo/?lesson=14

取得した課番号をGoogle Apps Script APIへ渡す。

カードデータ

APIから取得したデータをカードとして保持する。

各カードには、

kanji
hiragana
thai
front
back

を持つ。

表面・裏面表示

最初は表画像を表示する。

画面をクリックすると裏画像を表示する。

もう一度進むと次のカードの表画像を表示する。

表面・裏面の切り替えとカード移動を管理する。

カード移動

画面のカード領域をクリックすると次へ進む。

Enterキーでも次へ進む。

Backspaceキーでは前へ戻る。

進行状況

画面上に、

現在のカード番号 / 全カード数

を表示する。

正解管理

「正解」ボタンを押すと現在のカードを正解として記録する。

同じカードについては一度だけ正解数を加算する。

画面には、

正解：○ / ○

を表示する。

書き込み

Canvasによる書き込み領域を用意する。

マウスとタッチ操作で文字を書くことができる。

「クリア」ボタンでCanvasの内容を消去する。

画面表示

タイトル：

漢字道場

タイトル横に：

トータルロゴ.png

を表示する。

画面下部に書き込み領域、説明文、正解数、クリアボタン、正解ボタンを配置する。

全体のデータフロー
「漢字リスト」で課ごとの漢字データを管理する。
表画像・裏画像のFile IDをF列・G列で管理する。
Google Apps Scriptが指定された課のデータを取得する。
Google Apps Scriptが漢字・ひらがな・タイ語・画像URLをJSONで返す。
「URL発行」から課ごとのGitHub Pages URLを取得する。
lessonパラメータ付きで漢字道場を開く。
WebアプリがAPIから指定課のカードデータを取得する。
表画像を表示する。
画面操作またはEnterキーで裏画像を表示する。
次のカードへ進む。
正解ボタンで正解数を記録する。
Canvasで回答を書き、クリアボタンで消去する。
