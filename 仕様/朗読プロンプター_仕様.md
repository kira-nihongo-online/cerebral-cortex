GitHub / GAS

## 内容

【基本仕様】
GitHub Pagesで動作する朗読用プロンプター。

【授業モード】
・教材画像を縦方向に表示する。
・教材ごとのMP3音声を再生する。
・再生／一時停止／リセットができる。
・スクロール速度を変更できる。
・手動スクロールに対応する。
・READ LINEを上下に移動できる。
・PC、Android、iPhone、iPadで操作できる。

【コンテストモード】
・コンテスト用画像を表示する。
・制限時間をMM:SS形式で設定する。
・設定した制限時間に合わせて自動スクロールする。
・残り時間をタイマー表示する。
・コンテスト用TTSテキストを取得して音声再生する。
・コンテストモードでは通常のスクロール速度変更を使用しない。

【教材切替】
・URLのlessonパラメータから授業教材を指定する。
・URLのcontestパラメータからコンテスト教材を指定する。

【音声】
・音声ON/OFFを切り替えられる。
・授業モードでは教材MP3を使用する。
・コンテストモードではTTSを使用する。

【表示】
・教材画像を縦方向に連続表示する。
・画面上にREAD LINEを表示する。
・ヘッダーにモード、操作ボタン、音声、速度、タイマーを表示する。
