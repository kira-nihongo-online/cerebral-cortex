# 数字道場 仕様

## 1. 目的

指定した範囲から数字をランダムに生成し、
生成された数字を漢数字に変換して確認・読み上げできるWebアプリ。

## 2. 数字生成

以下の値を指定して数字を生成する。

- 最小値
- 最大値
- 出力数

「重複なし」を有効にした場合、
同じ数字を複数回生成しない。

## 3. 数字の表示

生成された数字は、数字ごとに1行で表示する。

各数字にはチェックボックスを付ける。

## 4. 漢数字への変換

数字のチェックボックスをONにすると、
その数字を漢数字へ変換して表示する。

対応する単位は以下。

- 一
- 二
- 三
- 四
- 五
- 六
- 七
- 八
- 九
- 十
- 百
- 千
- 万
- 億

最大9桁（一億）まで対応する。

## 5. 音声読み上げ

数字のチェックボックスをONにすると、
表示された漢数字を日本語音声で読み上げる。

音声はブラウザの Speech Synthesis API を使用する。

音声の選択は、

1. 「七海」を含む音声
2. 「Nanami」を含む音声
3. lang が「ja-JP」の音声

の順で優先する。

## 6. チェックを外した場合

チェックボックスをOFFにすると、
表示されていた漢数字を消す。

## 7. 音声再生

新しい数字を読み上げる前に、
現在再生中の音声を停止する。

## 8. 現在の実装

現在の完成版は GitHub の `suuji-dojo` リポジトリにある `index.html`。

この仕様は現在の完成コードを基準とする。
